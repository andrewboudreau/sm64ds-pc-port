# The two ROM pointer tables the sweep found -- their CALLEES.
#
# port/tools/ptr_audit.py intersects romdata.py's NAMED list with
# config/arm9/relocs.txt and reports every named symbol whose bytes
# contain a relocated word. Two of its answers are tables that matched
# code indexes and CALLS. Both are hosted with real host function
# pointers in port/hal/ptr_tables.cpp, which is only possible if the
# callees exist as host code -- that is this list.
#
# Nothing here is new decomp. Every file is matched src that had simply
# never been named by any slice, because the only thing naming it was a
# table of bytes.

# ---- the card command table, fsi_default_command[9] ----
# FSi_TranslateCommand does `ret = fsi_default_command[idx](self)` -- nine command
# handlers for the backup-media engine, indexed by the command id its
# callers pass (2, 3, 7, ...).
src/engine/fs/FS_CommandDefault.cpp
# src/CpuCopy8.c is deliberately NOT here. It is an asm primitive -- a
# hand-tuned unaligned block copy with no C body to compile -- and
# FSi_GetPathCommand is its only caller in this slice. hal/ptr_tables.cpp carries
# the host equivalent.

# ---- the camera-script command table, the 39 records at 0x02086bc0 ----
# _Z16RunCameraCommandP9dCamera_cPhii copies the 39 records into sScriptOps$2629[39] and
# dispatches `(cam->*sScriptOps$2629[msg[6]])(msg + 7, beg, end)` -- the
# camera half of the kuppa/cutscene script _ZN11KuppaScript7ProcessEv walks. It is
# generated by hostgen (CMakeLists.txt GATE13_SYMS, MG_PMF_CALL swaps that
# one call for a cdecl call on the seeded host handler; lane shadow-A); its
# src line is in slice_gate10.txt and skipped there.
# The 39 handlers plus the helpers they reach that nothing else links.
src/engine/view/d_camera_dtor.cpp
src/engine/view/d_camera.cpp
# _Z13func_020078c4P9dCamera_cPh: HOST COPY at unmatched/Camera_ApproachAngleVeneer.cpp (wired in
# CMakeLists). The matched C calls ApproachAngle with four arguments; the fifth
# (maxStep) rides the stack as 0, which cdecl does not stage, so the host copy passes
# the fifth argument (0) explicitly. See that file's header.
src/engine/view/d_camera.cpp
src/KuppaScript.cpp
src/unnamed/ov002/func_ov002_020effb8.cpp

# ---- the one-word table, data_0209a03c ----
# run link100, lane GLOBALS. relocs.txt has `from:0x0209a03c to:0x02057e30`:
# the .data word AT 0x0209a03c is a relocated function pointer, so romdata's
# raw bytes there are a DS address, and src/func_0201a490.c CALLS through it
# (`data_0209a03c(data_0208ee60)`) in the ROM's pre-main boot. hal/ptr_tables
# .cpp binds the word to the host function; this row is the callee, listed
# here for the same reason as everything above it -- the only thing that
# named it was a table of bytes. The ROM body is `bx lr`.
src/unnamed/arm9/0205/func_02057e30.c
