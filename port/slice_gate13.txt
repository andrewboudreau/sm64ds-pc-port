# Gate 13: the real Camera actor.
#
# The hand-tuned follow camera in walk_window is replaced by the ROM's own:
# Camera::Behavior runs the 19-state machine, Camera::Render builds the
# projection and view matrices and pushes them at the geometry engine, and
# GetAngleToCamera reads the heading the camera itself published.
#
# Everything below is MATCHED in src -- no new decomp. One file the port
# cannot take verbatim lives in port/unmatched/ instead and is listed in
# CMakeLists.txt: ChangeArea (r0 ride-through). _ZN9dCamera_c10EnterStateEv / _ZN9dCamera_c11UpdateStateEv
# (mwcc PMF dispatch, hostgen CALL_STATE_FN into hal_call_camera_state_fn),
# G3i::PerspectiveW_ / G3i::LookAt_ (register-bound MMIO pointers, hostgen
# MMIO_PTR; PerspectiveW_'s DIVCNT seam is an MMIO_EXTERN entry),
# Camera::Render, VEC_Mag and cstd::ldiv_result go through hostgen
# (CMakeLists.txt GATE13_SYMS).
