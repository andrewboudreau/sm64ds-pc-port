# W23-5 IRQ TABLE (run linkfull, lane IRQTAB1; LINK15 batch W23-5).
#
# The game's own interrupt registry, linked into walk_window and
# walk_window_hires in place of the host copies ntr/runtime.cpp kept. Read by
# the "W23-5 IRQ TABLE" block at the end of port/CMakeLists.txt, which also
# sets NTR_ROM_IRQ_TABLE on the two game libraries (ntr_wide_rt, ntr_hires) so
# their runtime.cpp stops defining these names and dispatches out of the ROM's
# table instead. The smoke probes link the plain ntr library and keep the host
# copies: they have no ROM vector table to read.
#
# Verified by ROM address against extracted/arm9_dec.bin (base 0x02004000):
#
# src/_ZN3IRQ13GetIRQHandlerEj.cpp        arm9 0x02056ee4, 0x8c
#     IRQ::GetIRQHandler(mask): the lowest set bit of the mask is the IRQ bit
#     number; bits 8..11 answer OSi_IrqCallbackInfo[i - 8].handler, bits 3..6
#     OSi_IrqCallbackInfo[i + 1].handler, every other bit OS_IRQTable[i]. Callers:
#     MI_SendGXCommandAsync (the display-list pump saves the geometry-FIFO handler it
#     replaces) and dScMgLuigi_c::AfterCleanupResources, plus this port's own
#     VBlank dispatch (hal/boot2_thread.cpp, hal/os_thread.cpp) and the HBlank
#     trace line in ntr/rt.cpp.
# src/_ZN3IRQ13SetIRQHandlerEjPFvvE.cpp   arm9 0x02056f70, 0x90
#     IRQ::SetIRQHandler(mask, fn): every set bit of the mask, the same
#     diversion; a diverted slot also gets argument 0 and enabled 1. Callers:
#     _Z13func_0201a4e4v (VBlank), the dWipe_c setters and func_0202fb30 (HBlank
#     arm and disarm), MI_SendGXCommandAsync / MIi_DMACallback (geometry FIFO),
#     PXI_InitFifo (IPC receive), OS_InitTick (timer 0), dScMgLuigi_c's iris.
src/engine/os/OS_Interrupt.cpp
#
# THE IE PAIR, through hostgen (the CMake block builds build/host-src copies of
# these two rows and compiles those): each body pokes IME (0x4000208) and IE
# (0x4000210) through literal casts, and hostgen's MMIO rewrite routes them to
# the port's mapped I/O window the way src/_ZN3IRQ7SetIRQsEj.cpp is routed for
# slice_link21.txt. Both registers are plain read/write latches on the DS.
#
# src/_ZN3IRQ10EnableIRQsEj.cpp           arm9 0x02056de0, 0x38
#     saved = IME; IME = 0; old = IE; IE = old | mask; IME = saved; return old.
#     Callers: the dWipe_c setters (mask 2), MI_SendGXCommandAsync (0x200000),
#     OSi_EnterDmaCallback (a DMA channel's bit; it reads the old word back),
#     OSi_EnterTimerCallback / OSi_SetTimer (timers), PXI_InitFifo (0x40000),
#     func_0204175c (card), OS_InitTick (8), dScMgLuigi_c's iris.
# src/_ZN3IRQ11DisableIRQsEj.cpp          arm9 0x02056d98, 0x48
#     the same bracket, IE = old & ~mask. Callers: func_0202fb30 (the HBlank
#     disarm), MIi_DMACallback (the pump's last chunk), IRQ::DmaTimHandler,
#     OSi_ArrangeTimer / OS_InitAlarm / OS_InitVAlarm, dScMgLuigi_c.
#
# NOT HERE: src/_ZN3IRQ15ClearInterruptsEj.cpp (0x02056d64, 0x34). It stores
# the mask into IF (0x4000214), which the DS clears bit by bit on a store and
# ntr/io.cpp latches plain; see its PORT_HOST_ABI tag in ntr/runtime.cpp.
